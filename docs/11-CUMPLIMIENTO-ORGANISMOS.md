## 1. DINAVISA — el gate de perfumes/cosméticos (si se elige ese nicho)

La decisión de nicho (doc 10) tiene una variable nueva: **los perfumes están regulados por DINAVISA** (Dirección Nacional de Vigilancia Sanitaria):

- **Resolución DINAVISA N° 189/2022**: requisitos de habilitación para establecimientos que **importan** productos de higiene personal y cosméticos (perfumes incluidos).
- **Importador habilitado**: se requiere autorización de apertura vigente (código INS-DGV-008) para importar formalmente — riesgo I y II.
- **Muestras**: se permite importar **hasta 30 unidades** para estudios de mercado — el size exacto de una validación fase 0.
- Proveedor CDE ya habilitado como importador = el trámite es de ELLOS, no nuestro (verificar habilitación del mayorista antes de publicar la categoría).

**Implicancia de nicho:** perfumes = mejor margen (30%+) PERO capa regulatoria encima. Los otros dos finalistas (audio/gaming accesorios, accesorios Apple) **no tienen gate DINAVISA** → fase 0 más rápida. Decisión documentada: validar audio/gaming primero (sin gate), perfumes como fase 2 con proveedor habilitado verificado.

## 3. Cosas a hacer que la investigación agregó

1. **Verificación de habilitación DINAVISA del proveedor** como paso del onboarding de mayoristas (columna en la tabla canónica) — aplica solo a categorías reguladas
2. **Validación fase 0 con 30 unidades**: el marco legal de muestras de DINAVISA calza exacto con nuestro plan de validación de nicho — importar 30, medir, decidir
3. **SEDECO posture**: publicar política de garantía/devolución con formulario de reclamo visible — reduce riesgo de mediación formal
4. **Registro DINAPI de la marca** (ya en doc 10 §8) — confirmado como paso previo a cualquier gasto de marca
